# 📊 AI-Powered Customer Churn Prediction System

## 📌 Overview

The AI-Powered Customer Churn Prediction System is a machine learning-based web application that predicts whether a telecom customer is likely to leave the company.

The system analyzes customer demographics, service usage, and billing information to identify customers who are at risk of churning.

An interactive Streamlit web interface allows users to enter customer details and instantly receive a churn prediction.

---

## 🎯 Problem Statement

Customer churn is one of the biggest challenges faced by telecom companies.

The objective of this project is to develop a machine learning model that can predict customer churn and help companies identify customers who are likely to leave.

Early prediction can help businesses improve customer retention strategies and reduce revenue loss.
